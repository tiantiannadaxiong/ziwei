## 复现

预览：`node site/preview.mjs`，访问 `http://127.0.0.1:8000/`。样板可访问同端口的 `/design-review.html`，或使用 `node site/preview-review.mjs` 启动独立的 8014 端口。

静态检查：`node tools/check-artbook.mjs`。

已有 Playwright 时，在仓库根目录执行：

```powershell
node tools/review-browser.mjs artifacts/artbook-review http://127.0.0.1:8000/
node tools/review-browser.mjs artifacts/artbook-sample http://127.0.0.1:8000/ review
```

必要时通过 `PLAYWRIGHT_MODULE` 指向已有包。Windows 默认使用已安装的 Edge。每步浏览器操作有超时限制，执行时打印各尺寸和缓存检查的进度；失败时 `checks.json` 记录错误。
